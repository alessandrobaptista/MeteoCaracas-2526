# MeteoCaracas-2526

MeteoCaracas es una aplicacion que permite consultar el clima actual y a su vez el historial de distintos municipios y localidades de Caracas.

Antes de iniciar el sistema del programa, es necesario descargar las librerias requests y matplotlib para el correcto funcionamiento del mismo.

GUIA DE USO

    Al inicializar el programa se observará un menú con 5 opciones, debe escribir el número de la opcion que desea elegir y presionar "Enter":

1.Ver resumen de los municipios y coordenadas: Se muestra un reporte cuantitativo detallado de las localidades que tienen y no tienen datos geográficos válidos.

2.Consultar clima actual: Permite buscar una localidad (navegando en el menu o escribiendo el nombre de la misma) para ver su temperatura, humedad, viento y condiciones actuales.

3.Estadísticas y gráfica de cobertura: Genera un ranking con la localidad mas fría y mas cálida que se haya consultado en la sesión abierta, a su vez, muestra un gráfico con los datos del sistema.

4.Consulta de datos históricos: Permite ingresar un rango de fechas (AAAA-MM-DD) para ver como evoluciona el clima en una localidad, mostrando extremos anuales y un grafico de temperatura.

5.Salir: Cierra el programa
